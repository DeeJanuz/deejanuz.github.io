# deejanuz.github.io

Keeps the old Frametop one-liners working after the repo moved to the Frametop organization
(2026-10-09): `frametop/get.sh` and `frametop/uninstall.sh` download the organization's
(`frametop.github.io/frametop`) and run them with the same options, and `frametop/*.html`
redirect there.
